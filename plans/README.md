# Feature Plans

This directory holds one implementation plan per roadmap feature. Plans are created just before implementation so they describe the project as it actually exists.

Naming convention:

```text
F##_short_name.md
```

Examples:

```text
F00_project_foundation.md
F01_player_and_arena.md
F08_boss_and_victory.md
```

Use `FEATURE_PLAN_TEMPLATE.md` as the starting structure. A plan should define one session-sized change, not repeat the entire game design, and should be updated with verification and completion notes during implementation.

The ordered feature list and dependencies live in `../GAME_PLAN.md`. Current truth and handoff evidence live in `../PROGRESS.md`.
